# TodoList —— 待办事项追踪工具

面向个人 / 小团队的轻量级待办事项追踪工具：**单机部署、零外部依赖、跨平台运行**。仅用 Python3 标准库 + SQLite，可打包为单文件 exe 双击即用。

## 功能特性

- **5 大视图**：列表（树形 + 拖拽排序）、看板、甘特图、日历、归档
- **字段齐全**：负责人、状态、优先级、进度、计划/实际完成时间、备注、标签、前置依赖、评论
- **数据能力**：JSON 导入导出、自动归档（90 天 + 已完成）、SQLite 单文件存储、跨机器拷贝即迁移
- **视觉体验**：深 / 浅双主题、响应式布局
- **邮件提醒**：计划完成日前一天 + 当天自动向指定邮箱发送到期提醒
  - 同一收件人的多个事项**合并成一封**发送
  - 美观的 **HTML 邮件**（彩色优先级 / 进度条 / 标签徽章），并带纯文本降级
  - 发送失败在**界面弹窗**提醒，并自动重试
  - 事项可单独指定提醒邮箱，未指定则发到默认收件邮箱

## 快速开始

### 源码运行（需 Python 3.8+）

```bash
python app.py        # 打开 http://localhost:8000
```

### Windows 免安装运行（无需 Python）

1. 双击 `dist/TodoList.exe`，1.5 秒后自动打开浏览器
2. 数据文件 `data.db` 自动生成在 exe 旁边，所有数据存于此
